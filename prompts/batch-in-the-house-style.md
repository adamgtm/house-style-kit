# Make a batch in the house style

Use this when agents need to make many of something at once: a thumbnail for every old post, a chart for each chapter, a card for each customer. One prompt per item drifts. A brief, a scripted check and a fresh reviewer keep the whole batch at your bar.

```text
I need [how many] [things], one for each [item]. Run it as a batch with a quality bar.

1. Gather first. Put each item's source material (the text, the images, the data) in its own folder, so every agent works from the same evidence.
2. Write the brief before any agent starts: the rules for this format (from my standard and lessons), two of my approved examples to match, where each item's material is, and what each agent must report back. Save it next to the batch.
3. Draft. Split the items across a few agents. Each one follows the brief, builds its items, looks at every result at the size people will see it, and writes a short note per item: what it chose, where every fact and number came from, and any call it couldn't make.
4. Check with a script, not by eye. Quotes match the source exactly, every number appears in the source, the builder (if there is one) passes, nothing is missing. Fix failures before review.
5. Review fresh. A new agent that hasn't seen the drafters' reasoning judges every item against my approved examples: ship or fix, with the exact fix. It also looks across the batch: the same image twice, near-identical items side by side, a series that doesn't match.
6. Apply the fixes and run the check again.
7. Show me one review page: every item together, the way people will see them, then one panel per item. Put only the calls that change what an item says at the top, five at most. Decide the small ones yourself and say what you decided.

Don't publish or upload anything until I approve the page.
```
